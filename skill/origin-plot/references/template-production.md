# 批量采集与自制模板

## 采集上游原生模板

本库的上游为 [OriginLab Templates](https://github.com/originlab/Templates)。发行包固定到一个提交，中文目录按上游 `package.ini` 和清单生成。维护者更新时，在独立目录调整源码 `tools/sync_official.py` 中的提交、校验值与该版本的预期清单，再运行 `fetch` 和 `verify`。比对新增、删除、更名、最低 Origin 版本和 OriginPro 要求，通过后再替换发行目录。

每个模板连同示例工程、预览、许可和配套文件整目录保存。登记其他来源时，记录作者、原始链接、版本、取得日期和再分发许可。仅供在线查看的参考图保留来源链接与图型说明。自行建设的数据与模板另设 ID，能够追溯每个文件的创作来源。

## 为每种图型制作两个例子

1. 定义研究问题和输入。写明每行代表什么、必需列、单位、分组和允许的空值。直方图输入原始观测，回归系数图输入估计值与既有区间，XRD 堆叠只向显示强度加偏移。
2. 准备独立的 A、B 两个数据集。B 改变观测值并覆盖一种结构变化，例如组数、测量范围或行序。先算出应当成立的结果，例如各组 Likert 类别占比之和、直方图各箱频数、XRD 的峰位和各系列偏移。
3. 在 Origin 中用 A 创建图页。分别保留原始表和用于绘图的转换表，为轴、单位和图例命名。保存原生图模板 OTPU，同时保存带数据和图页的示例工程 OPJU。
4. 从已存的 A 模板新建图页并绑定 B。核对每条曲线或矩阵实际引用的 B 数据及读回值，再修改一个图形属性、另存并重新打开。分别导出真实预览，记录工程、模板、导出图和哈希。
5. 在最终栏宽检查两个例子的图例、裁切、轴刻度、单位和面板标识。涉及期刊时另外核对真实 PDF/TIFF 导出报告。保留自动验收结果、视觉复核人及具体缺陷记录。

## 给子代理派工

在安装目标项目中用下列命令导出工单。移除 `--ids` 可列出全部 20 套。

```powershell
py -3.13 .\.origin-plot\launch.py qualify work-orders --ids histogram likert xrd-stack --output .\工单
```

按配方 ID 分配各自的目录。每个子代理可以独立维护输入定义、A/B 数据、预期统计结果和参考布局。将实机任务交给一个 Windows Origin 执行器串行处理，避免两个任务争用活动工程。由另一位审阅者对照工单和最终尺寸的原生导出图，记录“通过”“需修订”及依据。Matplotlib 参考图与真实 Origin 导出图在目录中分别标注。

在原生验收目录内，每种图型的 `native.json` 给出 A/B 工程、复用模板、两张预览与改图副本的位置。汇总 `qualification.json` 收录失败原因与环境阻塞。若只有配方复绘成功，模板复用项会保留未通过的原因。
